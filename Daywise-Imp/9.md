**Imperative**
kubectl run my-pod --image=nginx
kubectl delete pod my-pod

**Declarative**
cat <<EOF > nginx-pod.yaml
apiVersion: v1
kind: Pod
metadata:
  name: my-pod
spec:
  containers:
  - name: nginx
    image: nginx
EOF
kubectl apply -f nginx-pod.yaml


**In YAML, data is written as `key: value`. The value tells us what type of data it is** — such as String, Integer, Boolean, List, or Dictionary. 

Example:

```yaml
name: nginx      # String
replicas: 3      # Integer
enabled: true    # Boolean
ports:           # List
  - 80
```

So simply: **Key = name/identifier, Value = actual data + its data type.**
